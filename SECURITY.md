# Security policy

This is an independently signed, local-first Android project, not an official Xiaomi client.
The optional Shizuku/XMSF path can affect other apps' connectivity; privileged actions are
never required for offline transcription. If restoration fails, disable the option, restart
Shizuku, and if necessary restart the device before retrying.

For a suspected vulnerability, **do not post API keys, device tokens, private recordings,
process dumps or unredacted logs in a public issue**. Until a maintainer provides a private
contact channel, keep the report local and open a brief issue requesting a secure disclosure
route without including exploit details. No guaranteed support window or response SLA is
promised. Do not interpret a passing static check as a security audit.
